# GRAM-DISHA — Product Requirements Document (PRD)

**Project:** GRAM-DISHA (Rural & Semi-Urban Micro-Enterprise Intelligence)  
**Team:** ERGON (Smart India Hackathon 2026)  
**Version:** 1.0.0-PROD  

---

## 1. Executive Summary
GRAM-DISHA is an evidence-first, deterministic decision-support and business structuring intelligence platform designed for rural and semi-urban micro-entrepreneurs across India. It addresses the systemic information asymmetry, capital misallocation, and complex compliance landscape that hinder rural enterprise creation.

## 2. Core Value Propositions
1. **Evidence-First Decision Support**: Eliminates hallucinated business guidance by anchoring all recommendations to official datasets (LGD, AGMARKNET, MSME, KVIC, NSFDC, NABARD).
2. **Deterministic Financial Structuring**: Provides exact mathematical models for project cost estimation, EMI calculation, DSCR, Break-Even volume, and 12-month cash flows.
3. **Versioned Government Scheme Matching**: Multi-criteria rule engine matching entrepreneurs to central and state welfare schemes with verified rule versions and document matrices.
4. **Explicit Uncertainty (`UNKNOWN`)**: Rejects speculative numbers; clearly tags unavailable hyper-local data as `UNKNOWN` with confidence penalties.
5. **DISHA AI OS**: A persistent, multilingual, contextual co-pilot orchestrating user journeys without compromising deterministic outputs.

## 3. Scope & Platforms
- **Web App**: Desktop, Laptop, Tablet, Mobile responsive web application.
- **Language Support**: 23 Indian languages framework with primary localizations.
- **Auth**: Google OAuth + JWT session tokens.
